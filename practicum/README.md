## Как устроены решения

В каждом Python-файле условие записано в начальной модульной докстринге,
затем идёт решение. В HTML условия находятся в комментариях.
Для заданий Django сохранены изменённые файлы с исходными путями панелей
тренажёра. Остальные стартовые файлы предоставляет платформа.
Каждый каталог такого задания является самостоятельным учебным проектом.

На платформу отправляется код без добавленной докстринги с условием
или HTML-комментария. Условия остаются в локальном архиве.
Некоторые тесты проверяют структуру исходника, поэтому в HTML сохраняется
разметка стартера, кроме прямо требуемых изменений.

Отправки и отметки уроков подтверждены через API Практикума.

Папка `practicum` исключена из общего запуска `mypy`: независимые
тренажёры используют одинаковые имена модулей и собственные приложения.
Общий pytest пропускает `practicum`: учебные тесты запускаются в своих
тренажёрах. Ruff, Black и flake8 проверяют архив по настройкам репозитория:
79 символов и двойные кавычки в Python.

Изменения подготовлены в stage для просмотра. Новый коммит не создавался.
