# Сервис сокращения ссылок

## Назначение

Приложение предназначено для сокращения длинных URL-адресов: пользователь
передаёт сервису длинную ссылку и получает короткий адрес, которым удобно
делиться в мессенджерах, социальных сетях и печатных материалах.
Дополнительно сервис ведёт учёт переходов по созданным ссылкам и
контролирует срок их действия.

Приложение решает три задачи:

- длинные адреса неудобно пересылать и размещать;
- владельцу ссылки нужна статистика переходов по ней;
- часть ссылок должна быть доступна ограниченное время.

## Целевая аудитория

- SMM-специалисты и авторы контента, размещающие ссылки в постах и рассылках;
- маркетологи, которым нужна статистика переходов по рекламным материалам;
- преподаватели и организаторы мероприятий, публикующие ссылки на материалы;
- обычные пользователи, которым нужно передать длинный адрес в переписке.

## Предметная область

Предметная область — сокращение и учёт веб-ссылок. Пользователь регистрируется
в сервисе и создаёт короткие ссылки. Короткая ссылка состоит из домена сервиса
и короткого кода, который либо генерируется автоматически, либо задаётся
пользователем вручную. Короткий код уникален: занятый код повторно
использовать нельзя. У ссылки есть дата создания и срок действия, по истечении
которого переход по ней невозможен. Каждый переход по короткой ссылке
фиксируется и используется для формирования статистики.

## Основные сущности

- **Пользователь** — владелец коротких ссылок: логин, электронная почта,
  дата регистрации.
- **Ссылка** — исходный адрес, короткий код, владелец, дата создания,
  срок действия, признак активности.
- **Переход** — факт открытия короткой ссылки: ссылка, дата и время перехода,
  источник перехода.
- **Тег** — метка для группировки ссылок одного пользователя по кампаниям.

## Основные функции

1. **Создание короткой ссылки** — формирование короткого кода для исходного
   адреса автоматически или по пользовательскому алиасу.
2. **Проверка занятости короткого кода** — контроль уникальности короткого
   кода перед созданием ссылки.
3. **Проверка срока действия ссылки** — определение того, активна ссылка,
   истекает в ближайшее время или уже недоступна.
4. **Учёт переходов и статистика** — подсчёт количества переходов и средней
   интенсивности переходов по ссылке.
5. **Просмотр сведений о ссылке** — вывод карточки ссылки с исходным адресом,
   коротким адресом, сроком действия и статистикой.

## План развития

На следующих этапах планируется:

- перевод данных в коллекции, разбиение программы на модули и хранение
  ссылок и переходов в JSON-файлах;
- описание сущностей предметной области в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных и реализация моделей предметной области;
- реализация пользователей, регистрации и разграничения доступа;
- разработка REST API сервиса;
- контейнеризация приложения;
- настройка CI/CD.
