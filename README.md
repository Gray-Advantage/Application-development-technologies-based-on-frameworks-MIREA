# Сервис сокращения ссылок

Консольное приложение для сокращения длинных URL-адресов, учёта переходов
по коротким ссылкам и контроля срока их действия.

## Назначение

Приложение предназначено для сокращения длинных URL-адресов: пользователь
передаёт сервису длинную ссылку и получает короткий адрес, которым удобно
делиться в мессенджерах, социальных сетях и печатных материалах.
Дополнительно сервис ведёт учёт переходов по созданным ссылкам и
контролирует срок их действия.

Приложение решает три задачи:

- длинные адреса неудобно пересылать и размещать;
- владельцу ссылки нужна статистика переходов по ней;
- часть ссылок должна быть доступна ограниченное время.

## Целевая аудитория

- SMM-специалисты и авторы контента, размещающие ссылки в постах и рассылках;
- маркетологи, которым нужна статистика переходов по рекламным материалам;
- преподаватели и организаторы мероприятий, публикующие ссылки на материалы;
- обычные пользователи, которым нужно передать длинный адрес в переписке.

## Предметная область

Предметная область — сокращение и учёт веб-ссылок. Пользователь регистрируется
в сервисе и создаёт короткие ссылки. Короткая ссылка состоит из домена сервиса
и короткого кода, который либо генерируется автоматически, либо задаётся
пользователем вручную. Короткий код уникален: занятый код повторно
использовать нельзя. У ссылки есть дата создания и срок действия, по истечении
которого переход по ней невозможен. Каждый переход по короткой ссылке
фиксируется и используется для формирования статистики.

## Основные сущности

- **Пользователь** — владелец коротких ссылок: логин, электронная почта,
  дата регистрации.
- **Ссылка** — исходный адрес, короткий код, владелец, дата создания,
  срок действия, признак активности.
- **Переход** — факт открытия короткой ссылки: ссылка, дата и время перехода,
  источник перехода.
- **Тег** — метка для группировки ссылок одного пользователя по кампаниям.

На текущем этапе в программе реализованы сущности «Ссылка» и «Переход».
Сущности «Пользователь» и «Тег» будут добавлены при переходе к объектной
модели и веб-приложению.

## Основные функции

1. **Создание короткой ссылки** — короткий код генерируется из MD5-хеша
   исходного адреса или задаётся пользователем; адрес, код и срок действия
   проверяются перед созданием.
2. **Проверка занятости короткого кода** — контроль формата и уникальности
   кода.
3. **Проверка срока действия ссылки** — определение состояния ссылки
   («активна», «скоро истекает», «истекла») и просмотр только активных ссылок.
4. **Учёт переходов и статистика** — регистрация перехода с датой и
   источником, статистика по ссылке (количество переходов, переходы в день,
   популярность, источники) и общая статистика сервиса с рейтингом ссылок.
5. **Просмотр сведений о ссылке** — список ссылок с сортировкой по дате
   создания, коду или сроку действия и поиск по части кода или адреса.
6. **Удаление ссылки** — удаление ссылки вместе с её переходами.

Данные сохраняются в JSON-файлах и загружаются при следующем запуске.

## Формат данных

Ссылки хранятся в файле `data/links.json` в виде списка словарей. При загрузке
список преобразуется в словарь, ключом которого является короткий код: так
ссылка находится по коду сразу, а занятость кода проверяется одной операцией.

```json
[
    {
        "code": "mirea",
        "url": "https://www.mirea.ru/education/programmy-obucheniya/",
        "created_at": "2026-09-01",
        "expires_at": "2026-10-01"
    }
]
```

| Поле         | Описание                                          |
|--------------|---------------------------------------------------|
| `code`       | уникальный короткий код                           |
| `url`        | исходный адрес                                    |
| `created_at` | дата создания в формате ГГГГ-ММ-ДД                |
| `expires_at` | дата окончания срока действия в формате ГГГГ-ММ-ДД |

Переходы хранятся в файле `data/clicks.json` в виде списка словарей:

```json
[
    {
        "id": 1,
        "code": "py-docs",
        "clicked_at": "2026-08-03",
        "source": "direct"
    }
]
```

| Поле         | Описание                                  |
|--------------|-------------------------------------------|
| `id`         | идентификатор перехода                    |
| `code`       | короткий код ссылки                       |
| `clicked_at` | дата перехода в формате ГГГГ-ММ-ДД        |
| `source`     | источник перехода                         |

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.

Основной код использует только стандартную библиотеку Python, поэтому
`requirements.txt` содержит только инструменты разработки.

## Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```
