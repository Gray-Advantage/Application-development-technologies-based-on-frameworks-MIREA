# Сервис сокращения ссылок

Консольное приложение для сокращения длинных URL-адресов, учёта переходов
по коротким ссылкам и контроля срока их действия. Предметная область
описана объектной моделью: пользователи, ссылки и переходы представлены
объектами классов `User`, `Link` и `Click`.

## Назначение

Приложение предназначено для сокращения длинных URL-адресов: пользователь
передаёт сервису длинную ссылку и получает короткий адрес, которым удобно
делиться в мессенджерах, социальных сетях и печатных материалах.
Дополнительно сервис ведёт учёт переходов по созданным ссылкам и
контролирует срок их действия.

Приложение решает три задачи:

- длинные адреса неудобно пересылать и размещать;
- владельцу ссылки нужна статистика переходов по ней;
- часть ссылок должна быть доступна ограниченное время.

## Целевая аудитория

- SMM-специалисты и авторы контента, размещающие ссылки в постах и рассылках;
- маркетологи, которым нужна статистика переходов по рекламным материалам;
- преподаватели и организаторы мероприятий, публикующие ссылки на материалы;
- обычные пользователи, которым нужно передать длинный адрес в переписке.

## Предметная область

Предметная область — сокращение и учёт веб-ссылок. Пользователь создаёт
короткие ссылки. Короткая ссылка состоит из домена сервиса и короткого кода,
который генерируется автоматически или задаётся вручную. У ссылки есть
владелец, дата создания и срок действия. Каждый переход по короткой ссылке
фиксируется и используется для формирования статистики.

Правила предметной области:

- короткий код уникален: занятый код повторно использовать нельзя;
- перейти можно только по включённой ссылке, срок действия которой не истёк;
- отключённая ссылка остаётся в сервисе вместе со статистикой переходов,
  но новые переходы по ней невозможны;
- логин и адрес электронной почты пользователя уникальны.

## Основные сущности

| Сущность     | Класс   | Назначение                                        |
|--------------|---------|---------------------------------------------------|
| Пользователь | `User`  | владелец коротких ссылок                          |
| Ссылка       | `Link`  | короткая ссылка на исходный адрес                 |
| Переход      | `Click` | факт открытия короткой ссылки                     |
| Тег          | —       | группировка ссылок, появится в веб-приложении     |

### User — пользователь

Атрибуты:

- `id` — уникальный идентификатор пользователя;
- `username` — логин;
- `email` — адрес электронной почты;
- `registered_at` — дата регистрации.

Методы:

- `__str__()` — строковое представление пользователя;
- `validate_email()` — статический метод проверки адреса электронной почты;
- `from_data()` — метод класса, создающий объект `User` из записи JSON.

### Link — короткая ссылка

Атрибуты:

- `code` — уникальный короткий код;
- `url` — исходный адрес;
- `owner` — объект `User`, владелец ссылки;
- `created_at` — дата создания;
- `expires_at` — дата окончания срока действия;
- `is_active` — признак того, что ссылка не отключена;
- `short_url` — свойство (`@property`): полный короткий адрес.

Методы:

- `days_left()` — количество дней до окончания срока действия;
- `days_passed()` — количество дней, прошедших с создания;
- `is_available()` — можно ли перейти по ссылке на указанную дату;
- `get_state()` — состояние ссылки: «активна», «скоро истекает», «истекла»
  или «отключена»;
- `deactivate()` — отключение ссылки;
- `__str__()` — строковое представление ссылки;
- `validate_url()`, `validate_code()` — статические методы проверки адреса
  и короткого кода.

### Click — переход по ссылке

Атрибуты:

- `id` — уникальный идентификатор перехода;
- `link` — объект `Link`, по которому выполнен переход;
- `clicked_at` — дата перехода;
- `source` — источник перехода.

Методы:

- `__str__()` — строковое представление перехода.

## Взаимодействие объектов

Объекты связаны композицией: переход хранит объект ссылки, а ссылка —
объект своего владельца.

```text
Click
 └── link ──→ Link
               └── owner ──→ User
```

Поэтому данные связанных объектов доступны напрямую: `click.link.short_url`,
`link.owner.username`, `click.link.owner.email`.

Приложение работает с коллекциями объектов `list[User]`, `list[Link]` и
`list[Click]`. Операции над конкретным объектом реализованы его методами
(`link.deactivate()`, `link.is_available(today)`), а операции над
коллекциями — функциями модулей (`add_link()`, `find_links()`,
`register_click()`, `get_top_links()`).

## Основные функции

1. **Создание короткой ссылки** — владелец выбирается по ID, код генерируется
   из MD5-хеша исходного адреса или задаётся вручную; адрес, код и срок
   действия проверяются перед созданием.
2. **Проверка занятости короткого кода** — контроль формата и уникальности
   кода.
3. **Проверка срока действия ссылки** — определение состояния ссылки и
   просмотр только доступных ссылок.
4. **Учёт переходов и статистика** — регистрация перехода с датой и
   источником, статистика по ссылке (количество переходов, переходы в день,
   популярность, источники, последние переходы) и общая статистика сервиса
   с рейтингом ссылок.
5. **Просмотр сведений о ссылках** — список ссылок с сортировкой по дате
   создания, коду или сроку действия и поиск по части кода или адреса.
6. **Отключение ссылки** — ссылка перестаёт принимать переходы, статистика
   сохраняется.
7. **Работа с пользователями** — добавление, просмотр, поиск по логину или
   адресу почты и просмотр ссылок пользователя.

Изменения сохраняются в JSON-файлы перед завершением работы программы.

## Хранение данных

JSON используется для хранения данных, а объекты — для работы приложения.
При загрузке записи JSON превращаются в объекты, при сохранении — обратно в
записи. Связанные объекты в файлах заменяются идентификаторами: владелец
ссылки хранится как `owner_id`, ссылка перехода — как её короткий код `code`.
При загрузке по этим значениям находятся соответствующие объекты; записи со
ссылкой на несуществующий объект пропускаются с сообщением.

`data/users.json`:

```json
[
    {
        "id": 1,
        "username": "ivan_petrov",
        "email": "ivan@example.com",
        "registered_at": "2026-07-15"
    }
]
```

`data/links.json`:

```json
[
    {
        "code": "mirea",
        "url": "https://www.mirea.ru/education/programmy-obucheniya/",
        "owner_id": 2,
        "created_at": "2026-09-01",
        "expires_at": "2026-10-01",
        "is_active": true
    }
]
```

`data/clicks.json`:

```json
[
    {
        "id": 1,
        "code": "py-docs",
        "clicked_at": "2026-08-03",
        "source": "direct"
    }
]
```

Даты хранятся в формате ГГГГ-ММ-ДД.

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.

Основной код использует только стандартную библиотеку Python, поэтому
`requirements.txt` содержит только инструменты разработки.

## Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Тестирование

```bash
pytest -v
```

Тесты проверяют:

- создание объектов `User`, `Link` и `Click` и значения их атрибутов;
- строковое представление объектов и свойство `short_url`;
- методы классов: проверку адресов, состояние и отключение ссылки;
- создание, поиск, фильтрацию и сортировку ссылок и пользователей;
- связь перехода со ссылкой и ссылки с владельцем;
- правила предметной области: уникальность кода, недоступность истёкших и
  отключённых ссылок;
- учёт переходов и статистику.
